# Product media

The screenshots and walkthrough were captured from the project owner's ArkByte Voice Studio 1.2.0 application. They document the actual interface rather than mockups.

- `ArkByte-Voice-Studio-Walkthrough.mp4` is a curated 27-second, 1280 × 584 screen-only showcase. It contains no audio stream; the demo is intentionally muted to avoid redistributing source recordings or generated speech.
- `demo-preview.gif` is a lightweight five-second animated excerpt of the Custom Voice Lab.
- `../screenshots/` contains native-resolution interface captures. User/sample profile identifiers in the overview and deletion-dialog captures have been removed or redacted before publication.

No reference audio, generated voice sample, model checkpoint or private application data is included in this media directory.
