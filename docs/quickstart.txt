ARKBYTE VOICE STUDIO — WEB EDITION 1.2.0

QUICK START — WINDOWS 10/11 x64

1. Before extracting, right-click the downloaded ZIP > Properties. If Windows shows an Unblock checkbox under Security, tick it > Apply > OK. Do not disable SmartScreen or Defender.
2. Extract All to a writable folder under your user profile.
3. Double-click:

   INSTALL ARKBYTE VOICE STUDIO WEB.cmd

4. Wait for installation. It checks Node.js, Python and FFmpeg, creates a dedicated web Python environment, installs Next.js dependencies and the optional Chatterbox AI stack, and creates private local credentials. The first Chatterbox model-weight download happens when you first load the AI engine.
5. Double-click:

   START ARKBYTE VOICE STUDIO WEB.cmd

6. The web workspace opens at http://127.0.0.1:3000.

To stop services, double-click:

   STOP ARKBYTE VOICE STUDIO WEB.cmd

PRODUCTION BUILD

After installation, double-click BUILD ARKBYTE VOICE STUDIO WEB.cmd. Then start production mode in PowerShell:

   .\START ARKBYTE VOICE STUDIO WEB.ps1 -Production

SECURITY

The Next.js app and Python bridge bind to localhost only. Do not expose ports 3000 or 8765 to the internet or LAN. Creator data and local model caches are stored in %LOCALAPPDATA%\ArkByte Voice Studio and may be shared with the desktop edition when configured to the same data root. The bridge token is private in web\.env.local; never publish that file.

TROUBLESHOOTING

Installer logs: logs\
Backend logs: logs\backend.log and logs\backend-error.log
Next.js logs: logs\nextjs.log and logs\nextjs-error.log
AI logs: %LOCALAPPDATA%\ArkByte Voice Studio\logs\

See README.md and docs\ for complete setup, architecture, security and recovery instructions.

MAINTENANCE PATCH / ONE-CLICK RUNNER

Use RUN ARKBYTE VOICE STUDIO.cmd from the project folder. It checks the configured Python runtime, runs pip check, runs backend unit/API tests in a temporary data directory, runs the frontend TypeScript check and production build, and then starts the local production app. It does not create or replace virtual environments and it will not kill unknown processes occupying ports 8765 or 3000.

To add the optional VoxCPM adapters, run INSTALL VOXCPM MODELS.cmd and review the pip dry-run. The installer constrains already-installed packages so the existing CUDA/PyTorch stack is not upgraded. Model weights are downloaded only when the selected model is first used. Start with VoxCPM 0.5B; 6 GB VRAM is tight.

To stop the app, use STOP ARKBYTE VOICE STUDIO WEB.cmd. It only stops PID trees whose executable, command line, root and start time match the ownership record generated by the start script. It intentionally leaves unverified processes untouched.

RESPONSIBLE VOICE USE AND HISTORY DELETION (1.2.0-HF2)

- Voice profile creation requires confirmation that you own the voice or have the speaker’s explicit permission. Every generation request also requires a separate responsible-use acknowledgement; the local API rejects requests without it.
- Do not use ArkByte to impersonate, deceive, defraud, harass, create non-consensual intimate content or bypass identity/biometric verification. Disclose synthetic speech where a listener could reasonably mistake it for a real recording. Read docs\SAFE-USE-POLICY.md.
- In Generation History, use the trash icon on a row to delete that history item and its generated audio, or use Clear history to remove all history entries and generated audio. Both actions ask for confirmation.
- History deletion does not delete voice profiles, original reference recordings, saved projects, model caches or unrelated files. Bulk clearing is blocked while a generation is active.
- Deletion is normal filesystem deletion, not certified forensic erasure; backups and exported copies may remain. These safeguards are deterrence and user-attestation controls, not identity verification or a guarantee that misuse is impossible.
