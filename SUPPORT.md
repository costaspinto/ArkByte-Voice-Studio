# Support

Before opening an issue:

1. Read `README.md`, `docs/AI-ENGINE.md` and `docs/DEPLOYMENT.md`.
2. Run `DIAGNOSE ARKBYTE VOICE STUDIO WEB.ps1` on Windows.
3. Include the application version, Windows/Node/Python versions, the exact command, expected result and actual error.
4. Include only the smallest relevant log excerpt. Remove usernames, local paths, bridge tokens, scripts, voice-profile names and private media details.

Do not upload voice recordings, generated audio, databases, `.env.local`, PFX files or model weights to public issues.

This repository targets a single-user local installation. Public cloud hosting and multi-user deployment are not supported by the current security model.
